# Cal Poly (immersive) edition — photo drop folder

Drop image files here with the EXACT names below. Each one appears automatically
behind the words on the matching section. Until a file exists, that section shows
the green fallback field (never broken).

Format: JPG (or WebP), landscape, bright/high-contrast, ideally 2000px+ wide.
People-in-action shots read best behind big text.
